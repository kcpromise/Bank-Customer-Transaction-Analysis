# Bank-Customer-Transaction-Analysis

## 📊 Project Overview

The Bank Customer & Transaction Analysis project is a Power BI data analytics project designed to analyze customer profiles, bank accounts, deposits, loans and financial transactions.

The dashboard provides insights into customer demographics, account types, deposits, loans, transaction activity and overall banking performance to support data-driven decision-making.

## 🎯 Project Objective

The objective of this project is to analyze banking data and identify patterns in customer behavior, account activity, deposits, loans and transactions.

The analysis is designed to help banking management understand customer activity, monitor financial performance and identify areas that may require attention.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## 🗂️ Data Model

The project uses a relational data model connecting customer, account, transaction and loan information.

The account number serves as an important key for connecting relevant banking datasets and enabling integrated analysis across customer accounts, transactions and loans.

## 📁 Data Sources

The analysis uses multiple related datasets, including:

- Customer data
- Account data
- Transaction data
- Loan data

The datasets contain information relating to customers, accounts, transactions, deposits and loans.

## 🧹 Data Preparation

The data was cleaned and transformed using Power Query.

Key data preparation activities included:

- Cleaning and standardizing data types
- Handling missing values
- Removing inconsistencies
- Preparing customer and account information
- Preparing transaction data for analysis
- Creating relationships between related datasets
- Preparing calculated fields and measures for analysis

## 📌 Key Performance Indicators

The dashboard tracks important banking KPIs including:

- Total Customers
- Total Accounts
- Total Deposits
- Total Loans
- Active Accounts
- Loan-to-Deposit Ratio (LDR)
- Non-Performing Loans (NPL)
- Loan Repayments
- Transaction Volume
- Transaction Value
- Declined Transactions

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Customer demographics
- Account types
- Customer deposits
- Savings and current accounts
- Loan portfolio
- Loan repayments
- Transaction activity
- Transaction methods
- Transaction trends
- Geographic distribution of customers and transactions
- Declined transactions
- Customer and account activity

## 🔍 Key Insights

The analysis provides insights into customer behavior, account activity, deposits, loans and transaction patterns.

It helps identify trends in banking activity and highlights areas that can be monitored to improve operational and financial performance.

## 💡 Business Recommendations

Based on the analysis, banking management can use the dashboard to:

- Monitor customer and account activity
- Identify changes in deposit and loan trends
- Monitor loan performance
- Track loan repayments
- Monitor non-performing loans
- Analyze transaction activity
- Investigate declined transactions
- Understand customer demographics and account preferences
- Support data-driven customer and financial strategies
